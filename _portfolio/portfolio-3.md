# Instagram Clone Projects

This repository group contains two related projects that replicate core features of Instagram. One is a web version, the other is a Flutter mobile version. Both aim to deliver social feed, profiles, likes, comments, and basic user interactions.

## Projects Included

- [Instagram Web Clone](https://github.com/mohtasimbh/instagram-web-sh)
- [Instagram Flutter Mobile Clone](https://github.com/mohtasimbh/instagram-flutter-sh)

## Common Description

These projects are Instagram style social apps with user feeds, post creation, likes, comments, and profile views. They are built to be starting points for custom social platforms.

## Instagram Web Clone

### Description

A web based Instagram clone. Users view a responsive feed, click posts, like, and comment. The UI adapts to desktop and mobile screens.

### Features

- Responsive user interface
- Feed display
- Post interaction (like, comment)
- Profile page
- Navigation bar
- Image centric layout

### Tech Stack

- HTML
- CSS
- JavaScript
- Backend integration ready

### Structure

```
assets/         Images and icon files
css/            Stylesheets
js/             Frontend scripts
index.html      Main entry page
about.html      About or info page
profile.html    User profile page
posts.html      Post detail page
```

### Run Web

1. Clone the repo

   ```
   git clone https://github.com/mohtasimbh/instagram-web-sh.git
   ```

2. Open `index.html` in your browser

## Instagram Flutter Mobile Clone

### Description

A cross platform Instagram clone built with Flutter. Users browse a scrollable feed, like posts, and navigate between screens.

### Features

- Scrollable feed
- Post thumbnails
- Like button
- Comments view placeholder
- Profile screen
- Bottom navigation

### Tech Stack

- Flutter
- Dart
- Provider or state management
- Firebase backend (optional)

### Project Structure

```
android/        Android platform code
ios/            iOS platform code
lib/            Flutter app source
assets/         Icons and images
test/           Unit or widget tests
```

### Setup and Run

1. Clone the repo

   ```
   git clone https://github.com/mohtasimbh/instagram-flutter-sh.git
   ```

2. Install dependencies

   ```
   flutter pub get
   ```

3. Run the app

   ```
   flutter run
   ```
